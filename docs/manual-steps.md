# Manual Steps

These parts are not automated by `install.ps1`.

| Thing | Why | Workaround |
|-------|-----|------------|
| Windhawk mod installation | No CLI available | Install manually; see [Installation](installation.md#4-install-windhawk-mods) and [windhawk/README.md](../windhawk/README.md) |
| Nerd Font installation | Not on winget | Download from [nerdfonts.com](https://www.nerdfonts.com/font-downloads), then install manually |
| Flow Launcher settings | App-managed | Back up via app settings, then commit the backup to `flow-launcher/` |
| Windows accent color | Settings app only | Set manually; see [Installation](installation.md#5-set-windows-accent-color) |
